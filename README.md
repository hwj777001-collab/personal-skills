# Personal Skills · 个人 AI 技能库

将个人经验沉淀为可复用的 AI 工作流程。中文优先。

| Skill | 用途 | 状态 |
|---|---|---|
| [学霸笔记](xueba-notes/SKILL.md) | 将学习材料转化为可理解、可行动的笔记 | 既有技能，重整版 |
| [清楚又轻盈](clear-and-light/SKILL.md) | 微信及工作沟通润色 | 既有标准，重整版 |
| [能力载体匹配器](ability-to-form/SKILL.md) | 从个人能力到具体创造形式 | V1.0 |
| [APP 验收官](app-acceptance-review/SKILL.md) | 产品测试、体验评估与竞品研究 | 产品构想转为技能，实验版 |

## 使用
将所需目录复制到支持 Agent Skills 的工具所指定的技能目录，或直接将 SKILL.md 提供给 AI 并要求按其执行。具体安装方式取决于客户端。各技能均不保证工具权限或外部访问能力。
